# 🧁 Tumirio Treats - Cake Business Website

A professional, elegant website for **Tumirio Treats**, a custom cake business in Nairobi, Kenya.

## 🎯 Features

- **Hero Section** - Eye-catching introduction with WhatsApp order button
- **About Section** - Business story and location information
- **Cake Categories** - Display of cake types (Birthday, Wedding, Graduation, Cupcakes)
- **Gallery** - Beautiful showcase of cake designs
- **Order Process** - Step-by-step guide for customers
- **Contact Section** - WhatsApp, Instagram, and location links
- **Responsive Design** - Fully mobile-friendly
- **Smooth Animations** - Professional scroll effects

## 🎨 Design

- **Color Scheme:**
  - Primary: Deep Purple (#4A148C)
  - Accent: Gold (#D4AF37)
  - Background: White/Light Gray

- **Typography:** Modern, clean fonts for elegance
- **Layout:** Mobile-first responsive design

## 🚀 How to Use

### Local Development
1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process required - it's a static website!

### Deployment on GitHub Pages

1. Create a GitHub repository named `tumirio-treats`
2. Push all files to the repository
3. Go to **Settings → Pages**
4. Select **Branch: main** and **Folder: / (root)**
5. Click **Save**
6. Your site will be live at: `https://yourusername.github.io/tumirio-treats/`

## 📱 Customization

### Update WhatsApp Number
Replace `254712345678` in the following files:
- `index.html` - Hero section button and Contact section
- Update with your actual WhatsApp number (without +)

### Update Contact Information
- **Instagram:** Change `@tumirio_treats` in the Contact section
- **Location:** Update Nairobi to your actual location

### Add Custom Images
1. Create an `images/` folder in the project
2. Upload your cake photos
3. Update image URLs in the gallery section

### Modify Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #4A148C;  /* Deep Purple */
    --gold-color: #D4AF37;     /* Gold */
    --white: #FFFFFF;
    --light-bg: #F5F5F5;
}
```
